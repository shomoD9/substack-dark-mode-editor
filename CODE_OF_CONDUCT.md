# Code of Conduct

Nightdraft's community should be useful, respectful, and safe for writers and contributors.

## Expected behaviour

- Discuss ideas and code with patience and specificity.
- Welcome questions and different levels of experience.
- Respect privacy. Never request or expose another person's draft text, account data, or comment records.
- Keep feedback focused on the work and its effect on users.
- Accept maintainer decisions about scope, security, and release readiness.

## Unacceptable behaviour

Harassment, discrimination, threats, sexualized attention, personal attacks, deliberate disruption, and publication of another person's private information are unacceptable.

## Enforcement

Report conduct concerns privately through [GitHub private vulnerability reporting](https://github.com/shomoD9/substack-dark-mode-editor/security/advisories/new) and label the report as a conduct concern. The maintainer may edit or remove contributions, lock discussions, or temporarily or permanently restrict participation.

This code applies in repository spaces and when someone publicly represents the project.
