# Security Policy

## Supported version

Security fixes are applied to the latest release of Nightdraft.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/shomoD9/substack-dark-mode-editor/security/advisories/new).

Include the affected version, reproduction steps, impact, and a suggested mitigation when available. Do not attach private Substack drafts, authentication information, or exported comment records. A minimal synthetic example is preferred.

Please allow reasonable time for investigation and a coordinated fix before public disclosure.
