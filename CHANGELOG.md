# Changelog

All notable changes to Nightdraft are recorded here.

## Unreleased

### Changed

- Renamed the extension to **Nightdraft for Substack**.
- Reframed the product around its dark writing environment and private margin notes.
- Added open-source contribution, privacy, security, design, and release documentation.
- Added automated repository checks for the existing test suite.

## 1.1.2

### Fixed

- Preserved Backspace behaviour inside the private-comment editor despite Substack's page-level keyboard handling.

## 1.1.0

### Added

- Anchored private comment threads with replies, resolution, reattachment, JSON export, and Chrome Sync recovery.
- A stable manifest key for consistent unpacked-extension identity.
